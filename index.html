Bài giảng kèm code Python chạy được — bản dịch tiếng Việt không chính thức

Đọc sách trên arXiv

Bản dịch không chính thức. Đây là bản dịch tiếng Việt của Introduction to Computer Vision (Stan Birchfield), phục vụ mục đích học tập, phi thương mại. Nội dung gốc được phát hành theo giấy phép CC BY 4.0 (arXiv:2609.39627); bản dịch này đã được chỉnh sửa (dịch) so với bản gốc. Code Python, hình ảnh và kết quả chạy được giữ nguyên như bản gốc. Xem thêm README của repo.
